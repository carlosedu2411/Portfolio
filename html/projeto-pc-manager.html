Descrição do Projeto

O PC-manager é um aplicativo desktop desenvolvido para centralizar ações comuns do computador em uma interface visual única. A aplicação reúne atalhos para programas e sites, controles do sistema e recursos de entretenimento em um painel inspirado em uma central de controle.

Arquitetura e Tecnologias

  • Aplicativo Desktop: Construído com Wails para combinar uma interface web com recursos nativos do Windows.
  • Backend: Go responsável pela comunicação com o sistema operacional e pelas ações da aplicação.
  • Frontend: Interface responsiva criada com HTML, CSS e JavaScript.
  • Integração Windows: Uso de recursos nativos para áudio, mídia, notificações, atalhos e execução de aplicativos.

Funcionalidades Principais

  • Atalhos rápidos para abrir sites e aplicativos instalados.
  • Controle de volume e opção para silenciar o sistema.
  • Controles para reprodução de músicas e mídias.
  • Configuração e exibição de notificações do Windows.
  • Modo de tela cheia para uma experiência mais imersiva.
  • Plano de fundo personalizado e painel visual centralizado.

Objetivo do Projeto

O projeto busca tornar o uso diário do computador mais prático, reunindo controles e atalhos importantes em uma experiência simples, personalizável e agradável para usuários do Windows.
